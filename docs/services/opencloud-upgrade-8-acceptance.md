# Проверка обновления OpenCloud — 18 сентября 2026

На [cloud.met.surf](https://cloud.met.surf) установлен OpenCloud `8.0.1 rolling`, EuroOffice обновлён до `v9.3.4-hotfix.1`. Tika остаётся на `3.3.0.0-full`; отключение её интеграции с Paperless, сделанное владельцем, сохранено.

## Сохранность данных и работа приложений

| Проверка | Результат |
| --- | --- |
| Конфигурация перед переходом | `init --diff` на отдельной копии сообщил, что изменения не нужны |
| Вход | Вход администратора с прежним паролем из инвентори прошёл на 8.0.1 |
| Учётные записи | Идентификаторы двух пользователей совпали до и после обновления |
| Пространства | Идентификаторы четырёх записей `/me/drives` совпали; среди них два проектных пространства с суммарно около 26 ГБ данных |
| Контрольные файлы | DOCX, PDF и двоичный файл 2 МиБ загружены до обновления; после перехода их SHA256 совпали |

| Переиндексация всех пространств | Предыдущий запуск обработал три пространства и был прерван OOM; повторный запуск с `GOMEMLIMIT=1GiB` и последовательной обработкой ещё не подтверждён как завершённый |

Проверка контрольных сумм относится к специально созданным файлам, а не к побайтовому сравнению всех 26 ГБ пользовательских данных.

## Резервная копия и автоматизация

Перед сменой версий при остановленном OpenCloud создан снимок Btrfs с `ro=true`:

```text
/srv/storage/opencloud-upgrade-backups/20260918-7.2.4-to-8.0.1/storage
```

В соседнем каталоге сохранены файловый образ EuroOffice, исходные unit/env/labels, параметры контейнеров и SHA256 конфигурации OpenCloud. Каталог резервной копии доступен только root. Из снимка восстанавливается подкаталог `opencloud`, а не весь диск с другими приложениями.

В инвентори закреплены версия и репозиторий образа OpenCloud, поколение поискового индекса `v5` и версия EuroOffice. Через существующую роль auxiliary добавлена XML-конфигурация Tika с лимитом обработки файла 30 минут: прежние 5 минут вызывали перезапуск парсера и обрывы запросов во время полного сканирования. Пароль администратора и настройки WOPI/JWT не изменены; фильтр git-crypt и зашифрованный Git-формат проверены.

Локально прошли девять тестов, Ansible syntax check, `ansible-lint` с профилем production, YAML и Markdown lint. Тесты миграции проверяют пропуск повторного сканирования, блокировку одновременных запусков, отказ при старом образе, обработку частичной ошибки и отмены команды с кодом возврата `0`, а также ошибок извлечения текста, появляющихся только в журнале сервера.
